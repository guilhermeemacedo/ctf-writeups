# CTF Writeups – Web Security & AppSec

Olá! Me chamo Guilherme Macedo e sou estudante de Engenharia de Software,
com foco em Cibersegurança e Application Security (AppSec).

Este repositório contém writeups de desafios de CTF, principalmente na área de
Web Security, documentando o processo de análise, exploração e aprendizado
obtido a partir de cada desafio.

## 🎯 Objetivo
O objetivo deste repositório é consolidar conhecimentos práticos em
segurança de aplicações, demonstrando raciocínio técnico, fundamentos de
AppSec e boas práticas de documentação.

## 🛡️ Áreas de foco
- Web Security
- Application Security (AppSec)
- Broken Authentication
- Insecure Design
- Client-side vs Backend Security
- Conceitos baseados no OWASP Top 10

## 🧪 Plataformas utilizadas
- PicoCTF
- Laboratórios educacionais e públicos

## ⚠️ Aviso
Todos os desafios documentados neste repositório são públicos, educacionais
ou autorizados para fins de aprendizado. Nenhuma informação aqui deve ser
utilizada para fins maliciosos.
